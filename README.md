NotaFácil

Descripción

NotaFácil es un programa desarrollado en Python para gestionar las calificaciones de los alumnos de un curso. Permite cargar nombres y notas de dos parciales, calcular promedios y consultar información académica mediante un menú interactivo.

Funcionalidades

El programa permite:

Cargar alumnos con sus respectivas notas.

Validar los nombres y las calificaciones ingresadas.

Calcular el promedio individual de cada alumno.

Mostrar el listado de alumnos con sus notas y promedios.

Calcular el promedio general del curso.

Identificar al alumno con el mejor y el peor promedio.

Contar la cantidad de alumnos que promocionan, aprueban y desaprueban.

Ordenar a los alumnos de mayor a menor promedio mediante el método burbuja.

Buscar alumnos por su nombre.

Contar las vocales de un nombre.

Mostrar un nombre escrito al revés.

Navegar por las diferentes opciones mediante un menú interactivo.

Requisitos

Python 3.10 o superior, para utilizar la estructura match-case.

Visual Studio Code u otro editor compatible con Python.
